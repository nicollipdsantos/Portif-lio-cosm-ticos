# Nic Cosméticos

Landing page responsiva desenvolvida para o portfólio de uma revendedora de cosméticos das marcas Natura, Avon e Mahogany.

O projeto foi desenvolvido com foco em uma apresentação visual organizada, responsiva e acessível, utilizando HTML5 semântico e CSS3, sem JavaScript, CSS inline ou tags `<style>`.

## Descrição

A Nic Cosméticos é uma landing page criada para apresentar produtos de beleza e cuidados pessoais de forma simples e organizada.

A página funciona como uma vitrine digital, permitindo que os visitantes conheçam o portfólio de produtos, visualizem diferentes opções e entrem em contato diretamente com a revendedora por meio do WhatsApp.

O projeto foi estruturado com HTML semântico e possui adaptação para diferentes tamanhos de tela, proporcionando uma experiência adequada em dispositivos móveis, tablets e computadores.

## Funcionalidades

* Cabeçalho com identificação da marca e menu de navegação;
* Seção Hero com apresentação e chamada para ação;
* Seção Sobre;
* Cards de produtos e categorias;
* Galeria de produtos das marcas Natura, Avon e Mahogany;
* Links para contato via WhatsApp;
* Rodapé com informações do projeto;
* Estrutura semântica em HTML5;
* Layout responsivo;
* Recursos básicos de acessibilidade.

## Responsividade

O layout foi desenvolvido para se adaptar a diferentes dispositivos e resoluções.

Foram utilizadas Media Queries e recursos de CSS Grid e Flexbox para garantir que os elementos sejam reorganizados de acordo com o tamanho da tela.

O projeto foi pensado para funcionar em:

* Smartphones;
* Tablets;
* Notebooks;
* Desktops.

Também foram considerados cuidados para evitar rolagem horizontal em telas menores.

## Acessibilidade

O projeto utiliza recursos de acessibilidade para tornar a navegação mais clara e acessível.

Entre as práticas utilizadas estão:

* Uso de HTML5 semântico;
* Hierarquia adequada de títulos;
* Atributos `alt` descritivos nas imagens;
* Identificação das áreas de navegação;
* Uso de `aria-label` e `aria-labelledby` quando necessário;
* Link para acesso direto ao conteúdo principal;
* Destaque visual para elementos que recebem foco pelo teclado;
* Textos descritivos para links e chamadas para ação;
* Estrutura organizada para facilitar a interpretação por tecnologias assistivas.

A IA foi utilizada para auxiliar nas seguintes etapas:

<nav> para a navegação;
<main> para o conteúdo principal;

<figure> e <figcaption> para imagens que possuam legenda;
<footer> para o rodapé.

**Contribuição:** auxiliou na definição da estrutura semântica inicial da página e na organização das principais seções.
